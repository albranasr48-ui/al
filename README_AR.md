# النسخة النهائية — موقع متابعة أجهزة الصيانة

هذه النسخة مجهزة للنشر على Netlify وربطها بقاعدة بيانات Supabase. بيانات الأجهزة والإعدادات تحفظ في قاعدة بيانات مشتركة على الإنترنت، وليس في ذاكرة المتصفح.

## محتويات المجلد
- `index.html` واجهة العملاء ولوحة الإدارة.
- `style.css` التصميم المتجاوب.
- `app.js` منطق تتبع الأجهزة والإدارة.
- `config.js` بيانات الاتصال العامة بمشروع Supabase (تحتاج تعبئة).
- `supabase_setup.sql` إنشاء الجداول والصلاحيات ودوال البحث العامة.

## الخطوة 1: إنشاء قاعدة البيانات
1. افتح https://supabase.com وأنشئ مشروعاً جديداً.
2. افتح **SQL Editor → New query**.
3. افتح الملف `supabase_setup.sql` وانسخ محتواه بالكامل إلى المحرر ثم اضغط **Run**.

## الخطوة 2: إنشاء حساب الإدارة
1. من مشروع Supabase افتح **Authentication → Users** ثم أضف مستخدماً جديداً ببريد إلكتروني وكلمة مرور قوية. لا تفعّل التسجيل العام للمستخدمين إن لم تكن تحتاجه.
2. انسخ UUID الخاص بالمستخدم الذي أنشأته.
3. افتح SQL Editor وشغّل الاستعلام التالي بعد استبدال UUID بالقيمة الحقيقية:

   ```sql
   insert into public.repair_admins (user_id)
   values ('ضع-UUID-حساب-الإدارة-هنا');
   ```
4. لا تستخدم كوداً ثابتاً مثل A2060 للدخول. دخول الإدارة يتم بالبريد وكلمة المرور عبر Supabase Auth.

## الخطوة 3: ربط ملفات الموقع بقاعدة البيانات
1. في Supabase افتح **Project Settings → API** (أو قسم API Keys في الواجهة الجديدة).
2. انسخ **Project URL**.
3. انسخ **anon / publishable key** فقط.
4. افتح `config.js` وضع القيم مكان:
   - `PASTE_YOUR_SUPABASE_PROJECT_URL_HERE`
   - `PASTE_YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY_HERE`
5. لا تضع `service_role` أو أي secret key في ملفات الموقع أبداً.

## الخطوة 4: النشر على Netlify
1. فك ضغط ZIP على هاتفك أو كمبيوترك.
2. تأكد أن الملفات الخمسة الأساسية موجودة في المجلد نفسه.
3. افتح https://app.netlify.com/drop وارفع مجلد الموقع بعد فك الضغط، أو أنشئ موقعاً من مستودع GitHub.
4. بعد النشر افتح رابط Netlify الذي يظهر لك.

## الخطوة 5: الإعداد من الموقع
1. افتح رابط الموقع واضغط **دخول الإدارة**.
2. أدخل البريد وكلمة المرور التي أنشأتها في Supabase.
3. من تبويب **الإعدادات** أضف اسم المتجر ورقم واتساب خدمة العملاء بمفتاح الدولة، مثل 218 ثم رقم الهاتف من دون + أو مسافات.
4. من تبويب **الأجهزة** أضف الجهاز. بعد الحفظ سيظهر لك كود تتبع من 8 أرقام. أعطِ الكود للعميل.
5. يستطيع العميل إدخال الكود في خانة البحث الرئيسية. خانة البحث لا تعرض كلمة مرور الإدارة ولا تستخدم كود إدارة.

## الأمان وحدود النسخة
- مفتاح `anon/publishable` مخصص للاستخدام في الواجهة مع تفعيل RLS؛ ليس مفتاحاً سرياً. لا تضع مفتاح `service_role/secret` في الواجهة.
- قاعدة البيانات لا تسمح للزوار بقراءة جدول الأجهزة مباشرة؛ البحث العام يمر عبر دالة تعرض بيانات التتبع المحددة فقط.
- كود التتبع مكون من 8 أرقام، لذلك شاركه مع صاحب الجهاز فقط. للبيانات شديدة الحساسية، أضف تحققاً إضافياً مثل رقم إيصال/هاتف.
- استخدم كلمة مرور إدارة قوية وفريدة، وفعّل قيود تسجيل الدخول المتاحة في Supabase.
- لا توجد خدمة مجانية بلا حدود؛ راجع حدود الخطة الحالية في Supabase وNetlify.
- لم يتم نشر المشروع نيابة عنك أو إنشاء حساب Supabase؛ يلزم تنفيذ خطوات الإعداد أعلاه.

## استكشاف الأخطاء
- رسالة إعداد Supabase: تأكد أنك حفظت `config.js` بالقيم الصحيحة ثم أعد نشر الملفات.
- فشل الدخول أو تعذر تحميل الأجهزة: تأكد أن UUID لحساب الإدارة موجود في `repair_admins`.
- البحث لا يعثر على جهاز: تأكد من صحة الكود ومن أن الجهاز محفوظ في قاعدة البيانات.
- إذا عدلت `config.js` بعد النشر، أعد رفع الموقع أو أعد النشر.
